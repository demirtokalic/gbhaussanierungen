# GB Haussanierungen — pregled za klijenta

Sadržaj ovog foldera postaviti direktno u root GitHub repozitorija. index.html mora biti odmah vidljiv u repozitoriju, bez dodatnog GB-GitHub-Preview foldera.

GitHub: Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save.

Kontakt-forma je namjerno deaktivirana u ovom preview paketu. PHP datoteke nisu uključene. Telefonski i e-mail linkovi su aktivni. Preview ima noindex oznake; nemojte ovaj paket koristiti kao produkcijsku STRATO verziju. Za produkciju koristiti zaseban GB-STRATO-Paket.zip.
